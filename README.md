# Hotel_Booking-Analysis
This project focuses on analyzing hotel booking data to understand customer behavior, reservation cancellations, pricing patterns, and booking channels. The dataset is sourced from Kaggle and includes booking details for both city and resort hotels.

The main goal of this project is to explore factors affecting reservation cancellations and provide actionable insights that can help hotels improve pricing strategies, marketing decisions, and revenue management.

.

📊 Project Objectives

Identify key variables influencing hotel reservation cancellations

Analyze booking patterns across months, hotel types, and countries

Examine the relationship between Average Daily Rate (ADR) and cancellations

Provide data-driven suggestions to reduce cancellation rates

🛠 Tools & Technologies Used

Python

Pandas (Data Cleaning & Analysis)

NumPy (Data Handling)

Matplotlib (Data Visualization)
